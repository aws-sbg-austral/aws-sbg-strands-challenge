# Contador de palabras

Agente de ejemplo del challenge, hecho por [@Masega360](https://github.com/Masega360).

**Problema que resuelve:** saber cuántas palabras tiene un texto (por ejemplo, para no pasarte del límite de una consigna).

**Tools custom:**

- `contar_palabras(texto)`: devuelve la cantidad de palabras de un texto.

**Cómo correrlo** (desde la raíz del repo):

```bash
pip install -r agentes/Masega360/requirements.txt
python agentes/Masega360/agent.py
```
