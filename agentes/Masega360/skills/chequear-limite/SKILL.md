# Chequear un límite de palabras

1. Contá las palabras con la tool `contar_palabras`. Nunca las cuentes a ojo.
2. Compará el resultado con el límite que te dio el usuario.
3. Respondé en una línea: "Entra" o "Se pasa", cuántas palabras tiene y cuántas sobran o faltan.
4. Si se pasa, sugerí qué parte recortar primero.
